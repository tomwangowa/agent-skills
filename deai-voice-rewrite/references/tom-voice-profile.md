# Tom 口吻 profile

> 這是內建的靜態底稿，描述 Tom 寫對外稿時的語氣傾向。**它是「傾向」不是「檢查表」**——不要為了命中而每段硬塞。密度比照 Tom 的真實成品（克制、自然）。
> Tom 可隨時補代表作來精修這份檔；補進來時，更新下面的特徵與例句。

> ⚠️ **這個 skill 只做去 AI 味，不產內容。** 觀察 Tom 的精修成品時，要切開兩件事：他大量的編輯其實是**自己加回實質內容**（真實場景、同事對話、skill 緣由、數字、個人意見、推薦做法）——那是他在創作，**不是**這個 skill 該模仿、更**不是**該自動生成的東西（自己生成軼事／數字＝捏造事實，違反 Guard 1）。skill 交出的是一份乾淨的「去 AI 味底稿」，Tom 在上面長出故事與論點。**只學字詞／句法層的傾向；永遠不要為了「像 Tom」而自己編軼事、補數據、塞意見。**

---

## 一、語氣特徵（核心）

### 1. 軟開場
不直接丟結論砸人，先用一句「鋪墊」把人帶進來：
- 「我有個想法，就是…」
- 「先講一個我想了很久才想通的點」
- 「我先把結論講在前面，這樣就算你中間分心了，至少帶得走這一句」

### 2. 大量限定詞（hedging）
幾乎不把話講死，留餘地：
- 我覺得 / 倒是覺得 / 據我所知 / 見仁見智 / 理論上 / 老實說 / 其實 / 大概 / 差不多 / 不太（「又快、又**不太**容易出錯」）

### 3. 坦白講不確定、坦白講還沒做完
把限制與未知攤開講，當成可信度來源而不是弱點：
- 「我不知道有什麼方法可以…」
- 「老實說，我自己也還沒做完，但我看得到那道牆在哪」
- 「這種事我**不敢**讓 AI 直接下手」
- 「誠實 ≠ 扣分」——把講清楚限制當賣點

### 4. 破折號 `——` 與引號「」
用 `——` 補充、轉折、鋪陳；用「」框住要強調或要定義的概念：
- 「真正卡住我的，是三種『搞不清楚的狀況』」
- 「我得到的『信心』，我想特別說明一下：它不是因為我變得更信任 AI 了——其實剛好相反」

### 5. 隨口收尾
句尾常帶一個放鬆的小尾巴，不硬：
- 「…就是了」
- 「…就好」（「先試一種**就好**」）
- 「…而已」

### 6. 直接對讀者說「你」
像在面對面講，不是寫論文：
- 「你可以想成…」「你只要注意一件事」「回去看看你自己每天的開發流程」

### 7. 括號內補一句（雙向 gloss）
Tom 愛用 `（…）` 在術語旁補一句——可能補英文原名，也可能補白話。投影片上會被看到的字（Key message）尤其常見。**這是「替既有詞加註解」，不是新增內容**，可放心套；但別硬加，他只在會卡住的詞上補：
- 中→英原名：「工程系統（Harness Engineering）」「下次可以重跑（replay）的 golden artifact」
- 英→白話：「owner boundary（你不能隨便動到不屬於你的部分）」「schema drift（專案初期的協定會時常變動）」

### 8. 字詞偏好（二次精修萃取）
- **慣用詞**：整合（不用「外化／聚合」）、證據／證據鏈（prose 裡少用 evidence／evidence chain，但 Key message 可保留英文原詞）、形狀（不用 shape）。
- **偏文一點的隨性小詞**：頗為、硬梆梆的、沈迷、越跑越歪、做做樣子——Tom 會用，帶一點放鬆。
- **hedge 會再加重**：「不要相信」→「不要『太』相信」；「我覺得蠻準的」→「我自己覺得還頗為準確」。
- **掌控動詞是 Tom 的詞**：操控／駕馭／帶（見反指紋區的 carve-out，**不是**戰爭隱喻，保留）。
- **Agent 的代名詞「他／它」是 Tom 的選擇——不要正規化任何一個方向**：他同一段裡會用「它寫得快」（當機械主詞）也會用「質疑他、指導他」（當被對話、被指導的協作者）。看到就**保留原樣**，flag-don't-fix，別自作主張統一成「它」或「他」。

## 二、Tom 不做的事（反指紋）

- **不誇張、不喊口號**：不用「顛覆」「革命性」「徹底改變」「致命」這種字。
- **不堆排比金句**：不寫三句對仗的漂亮話收尾。
- **不裝權威**：不用「眾所周知」「毫無疑問」「顯而易見」。
- **不用戰爭隱喻**：作戰、戰場、火力、攻防、被殺、淪陷——一律不要（連「對付」都換掉，照 brief）。
  - ⚠️ **carve-out**：「操控／駕馭／帶」這類「上手、掌控」的動詞**不是**戰爭隱喻，是 Tom 自己的詞，**保留**——他甚至會主動加回來（「正確、有效地『操控』它」「『操控』Agent 的成熟度」「會『帶』它」）。要清的只有上面那串 combat 詞，別誤殺掌控動詞。
- **不堆形容詞**：白話、樸實，能用一個動詞講完就不加修飾。

## 三、密度提醒（最容易做錯的地方）

Tom 的成品是**克制**的。看一段真實的他：

> 「先講一個我想了很久才想通的點。我這套 harness，我一個人用的時候非常順，但它會這麼順，是有原因的——因為所有事情都只有一個源頭，就是我。」

注意：**一整段只有一個軟開場 + 一個破折號**，沒有把「老實說 / 其實 / 就是了」全塞進去。這才是對的密度。

反例（假 Tom，過量）：

> 「老實說，我倒是覺得，其實這套 harness 嘛——我自己用起來，據我所知，大概是非常順的就是了，理論上啦。」

塞滿 marker 反而不像人講話。**寧可少，不要多。**
