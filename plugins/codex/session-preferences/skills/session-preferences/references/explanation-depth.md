# Explanation depth

Apply to replies that state an important judgment or propose or change a
design, and to handoff or summary content that the user or another agent
will act on.

- Do not give only a conclusion. State the reasoning basis for each
  important judgment.
- For a design change, explain why, the scope of impact, the trade-off,
  and how it will be verified.
- Give a concrete example for a non-obvious concept.
- When information is insufficient, state the uncertainty: what is missing
  and which judgment it affects.
- Do not add narration that does not help the reader evaluate the point.
- Target: complete enough to evaluate, concise enough to work with.
  Test: the user should not need to ask for basic background to understand
  why the agent reached a judgment.
