# 決策：Attention Mod 使用有限範圍背景摘要

日期：2026-10-03  
狀態：Tom 已於 2026-10-03 確認此方向及書面設計。  
決策者：Tom。

## 問題與決策

Tom 回到目前的 Claude Code 工作階段時，希望瞄一眼側邊面板，就能接回工作脈絡。摘要要包含 Claude 的目前假設及最近證據，但不能把執行過工具當成任務已有進展。

採用事件狀態＋有限範圍的背景摘要。事件處理目前動作與可確認的等待訊號，模型只整理有來源的文字；摘要不進入主 Claude 的對話。素材大小封頂，有新資料才更新，模型呼叫開始時間至少相隔 60 秒。

## 研究與證據（決策當時）

| 方法 | 結論 | 證據界限 |
|---|---|---|
| `tech-feasibility` | Conditional-Go：官方 API 提供對話讀取、獨立模型呼叫、背景計時器及面板 | 尚未執行真實原型，不能宣稱不中斷或語意正確 |
| `critical-research` | 部分支持：有限素材可控制輸入範圍；可能漏掉早期決定，分支摘要也不能推定必然更省 | 未找到可直接代表此 Mod 與本機版本的效能比較 |

技術與操作：依 [API 文件](https://code.claude.com/docs/en/plugins/mods/api)，`model.complete` 無對話歷史，須自行提供素材；`model.fork` 沿用目前對話、模型與系統提示。背景計時器不啟動主工作的新回合。這些是介面契約，尚非本機執行證據。

成本：兩條路都使用方案額度或 API 用量。素材與頻率上限能限制請求規模，不能代替實際成本量測；不估算固定每小時金額。參考 [用量說明](https://code.claude.com/docs/en/costs) 與 [官方價格頁](https://claude.com/pricing)。

風險：依 [事件參考](https://code.claude.com/docs/en/plugins/mods/reference)，切換／清除後不會再次觸發 `session.start`，需另做重設與重建。依 [型別文件](https://code.claude.com/docs/en/plugins/mods/create)，本機產生的型別優先；公開型別檔版本較舊，不能照抄。

信任與使用範圍：這是自行撰寫、使用官方介面的個人 Mod，沒有爬取第三方服務或納入第三方 Mod 程式碼。官方 [overview](https://code.claude.com/docs/en/plugins/mods/overview) 明示 Mods 未沙箱隔離，因此限制本 Mod 的實際能力使用範圍仍有價值。沒有針對契約或法律合規作保證；廣泛訴訟／條款搜尋沒有找到直接針對此個人使用案例的判定，不代表沒有風險。

## 衝突與取捨

較完整的工作脈絡需要更多素材，限制輸入又可能遺漏早期決定。第一版保留目前目標的來源，再選近期對話與工具結果；承認節錄與資訊不足，不以連續摘要自我累積取代原始證據。

分支摘要可使用主對話的提示快取，但快取效益、模型選擇與對話長度共同影響用量；沒有實測不能據此認定更省。第一版優先選擇可明確限制素材的獨立摘要，代價是自行設計素材截取。

## 替代方向

| 方向 | 第一版未採用的理由 |
|---|---|
| 完整對話分支摘要 | 沿用主模型與較完整的脈絡，輸入範圍較難獨立控制；不保證摘要忠於目前方向或更省 |
| Settings hooks＋status line | 可處理基本事件狀態；依 [overview 的比較](https://code.claude.com/docs/en/plugins/mods/overview)，無 Mod 的互動面板能力，不符合已選的側邊面板 |

## 原型條件

若必要素材在主工作執行中不可用，或背景摘要阻塞工具／主工作，就重新評估方向。摘要失敗應降級為事件狀態與明示過時的舊摘要。

原決策當時尚未驗證精確本機型別、人工等待訊號、切換生命週期、摘要品質、真實用量與背景執行干擾。目前結果見 [原型驗證](../prototype-results.md)。2026-10-04 Tom 選擇接受完整、單一的 JSON code block；僅移除外框，來源、長度、欄位驗證不放寬。實測另增加脈絡／證據來源身分檢查，拒絕把使用者要求或工具參數引用為已觀察到的結果。完整設計見 [Attention Mod 設計](../superpowers/specs/2026-10-03-attention-mod-design.md)。
