# 決策：面板收起改成標題列 toggle

日期：2026-10-07  
狀態：Tom 於 2026-10-07 選定；實作版本 0.4.3。設計見 `docs/superpowers/specs/2026-10-07-collapse-panel-design.md`。

## 決策

- 底部的「收起」按鈕實際是 `$.ui.close`（整個關掉），名稱與行為不符，也和原生 × 重複，所以拿掉。
- 標題後面改放 toggle「收起面板／展開面板」。收起時只畫標題列和一行狀態；有問題或權限在等你時，那一行改顯示「需要你」，不讓收起藏住待回答訊號。
- 收起狀態只存記憶體，跨 `/clear`、`/resume` 保留，重載外掛才回到展開；不用 store 或檔案。

## 考慮過但未採用

| 方案 | 未採用原因 |
|---|---|
| 只改名為「關閉面板」 | 沒有達成「縮成標題」 |
| 收起時只留標題列 | 有問題等你回答時使用者看不到訊號 |
| 狀態點放在 toggle 旁 | 只有一顆點，使用者得猜黃色的意思 |
| 收起狀態跨重載保留 | 要用 store 或檔案，違反被動觀察 |

## 限制

- NOT VERIFIED：收起後面板外框會不會縮成兩行。`PaneOpenArgs.rows` 只是請求，dock 會忽略，對已開啟的 id 再 `open` 只算 retitle。要實機看 inline 與 dock 的實際高度，再決定要不要補「收起時重呼叫 `ui.open({rows:2})`」。
- NOT VERIFIED：48 欄寬下標題加按鈕會不會折行。
- 測試 kit 沒有 `$.ui.close`，原生 × 觸發的 `closed` 旗標失去自動化測試（原本靠底部按鈕觸發）。
