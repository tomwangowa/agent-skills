# Output Contract

## General
- Write in natural Traditional Chinese.
- Retain important English technical terms on first appearance with a concise Chinese explanation.
- Prefer narrative for semantic reconstruction; use tables only when comparison benefits from them.
- Cite/attribute source-specific claims when the environment supports citations.
- Clearly mark external verification separately from document content.
- Do not fill empty sections merely because a template contains them.

## Required opening: Document Profile
Place this before analysis unless verified upstream metadata is already visible immediately above the appended section.

Suggested compact form:

```markdown
## 文件來源
- **標題**:
- **作者**:
- **作者／發布機構**:
- **文件類型**:
- **發布日期**:
- **最後更新**: (if available)
- **版本**: (if applicable)
- **原始來源**:
- **原文連結**:
- **來源狀態**:
- **閱讀提醒**: (only if material)
```

## Quick output
Required concepts, not rigid headings:
1. Document Profile
2. What the document is and its main line
3. Chinese semantic reconstruction
4. Only necessary background
5. High-value knowledge
6. Material evidence caveat / Evidence Verdict when needed
7. Up to 2–3 derived insights
8. 3–5 retention points + one mental model

## Deep output
Cover, proportionally:
1. Document Profile
2. ORIENT
3. READ
4. UNDERSTAND / reasoning chains
5. DISTILL
6. CHALLENGE + Evidence Verdict
7. DERIVE
8. CONNECT/APPLY only when useful
9. RETAIN

## Synthesis additions
When requested/useful, add:
- Cross-source map
- Core mental models
- Agreements / genuine disagreements
- Collective knowledge gaps
- Knowledge stress test
- Teachable framework

## Evidence language
Avoid turning source claims into facts through grammar. Prefer explicit attribution for self-reported benchmarks, company claims, community posts, preprints, and secondary reporting.
