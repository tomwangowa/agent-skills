# 團隊指示範本

以下文字不包含維護者的個人語氣或私有路徑。先選擇實際安裝的套件，再加上團隊既有的審查、資料與發佈規則；不要把未安裝的入口寫成已可呼叫。

```text
Respect explicit user instructions and higher-priority policy.
Use skills exposed by the current runtime; registry mentions are not installation evidence.
For feature design, use the installed technical-decisions brainstorming skill.
For generic code review, first use the installed quality-gates native reviewer for this runtime.
Before claiming completion, use the installed quality-gates completion gate and actual evidence.
User-only skills require explicit user invocation; workflow approval does not authorize them.
Check required or conditional Superpowers skills at the selected workflow boundary.
Report missing skills and untested versions; do not claim compatibility from cache paths.
Do not invoke the retired Gemini reviewer or automatically send code to an external reviewer.
Keep personal preferences and journal settings outside plugin caches.
Preview and confirm configuration writes; preserve unrelated settings and user data.
Apply the team's normal commit, push and release approval rules.
```

日誌路徑與個人偏好由每個使用者自行設定，不放進 repository 共用指示。沒有安裝對話偏好套件時，工程套件仍能提供自己的路由；偏好 off 不移除工程檢查。
