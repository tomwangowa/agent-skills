# Reading Modes

## Auto
Default to Quick. Select Deep only when the user explicitly requests thorough understanding or the document is being used for research, design, or consequential decision support. Length alone does not trigger Deep.

## Quick
Goal: `這份文件值得我知道什麼？`

- Reading experience: roughly 5–10 minutes.
- Reconstruct the main line, not merely an abstract-like summary.
- Explain only prerequisites required to understand that line.
- Include evidence or limitations only when they change interpretation.
- Keep derived insights to the few that materially improve understanding.
- Retain 3–5 items.
- Skip CONNECT unless relevance changes whether deeper reading is worthwhile.

## Deep
Goal: `這份文件真正教會我什麼？`

- Build a complete mental model of the important material.
- Provide a Chinese semantic reconstruction sufficient to replace a first English reading.
- Reconstruct material reasoning chains and evidence boundaries.
- Critique source quality and applicability systematically but proportionally.
- Derive grounded insights, then connect to the user's context.
- Retain 5–10 items.

Depth follows information value: low-value sections may remain short.

## Deep Dive
Goal: `這個指定概念我想真的弄懂。`

- Use only the context needed for the named topic.
- Explain mechanism, evidence, reasoning, alternatives, and limitations.
- Link to other document sections only when needed.
- Do not repeat the full document analysis.

## Progressive Escalation

`Quick → Deep → Deep Dive`

Escalation is additive. Reuse completed provenance, mapping, and verified facts. Add the detail intentionally omitted at the previous level rather than generating a longer duplicate.
