# Long-form Traditional Chinese prose

Read this together with `deai-voice.md` before drafting a requested text or a
response with more than two prose paragraphs.

## Before drafting

- State the claim before adding decoration or framing.
- Keep an `X versus Y` construction only when X is a likely reader assumption
  and distinguishing it from Y changes the point.
- Use a list only for material that is genuinely parallel. Otherwise write the
  connection as prose.

## Silent final pass

Before replying, check whether the draft has:

- repeated section endings or miniature summaries that add no new point;
- transition labels that can disappear without changing the meaning;
- dashes doing the work of ordinary sentence structure;
- chained parallel phrasing that only repeats one idea;
- quantity words that do not identify a real count; or
- sentences carrying more logical steps than a reader can follow in one pass.

Rewrite only when the check improves clarity. Do the pass silently unless the
user asks to see it; do not impose word-count quotas.
