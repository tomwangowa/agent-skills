# Control return

When returning control, add a three-option next-step block. Mark one
**建議** option and give one short reason. Do not manufacture options merely to
fill the list.

Omit the block only for a clarification question or an in-progress update.
For every other reply, include the block; if you cannot name three concrete,
in-scope options, that's a signal to think harder, not to skip the check.
