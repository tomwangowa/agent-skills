# 「測試通過了」——真的嗎？

> *這是「當 AI 越來越好用，品質反而越來越差」系列的第 4 篇，也是第一幕「踩坑」的最後一篇。*
> *這一篇講的是：AI 說「完成了」的時候，你要怎麼確認它真的完成了。*

---

前幾篇講了可行性報告的幻覺、code review 的盲區。但有一個問題比這些都更基本，基本到我一開始根本沒意識到它是個問題：

**AI 說「任務完成」，那麼它真的完成了嗎？它跑過測試了嗎？**

---

## 「Done」的意思

我用 Claude Code 的習慣是這樣的：先讓它做計畫、切分任務，然後它一個接一個完成。每完成一個就打勾，很有成就感。

直到有一次，所有任務的 checkbox 都打勾了。Claude 直接跟我說：「所有任務已完成，要提交嗎？或是你還有其他想法？」

我愣了一下。我的媽，它連 code review 都還沒做呢。

那次之後我開始注意，叫它「每完成一個小任務，一定要 review code」。它照做了。但我漏了一個更根本的問題：**我從來沒跟它說「你怎麼保證任務是『真的』完成了？」**

這不是某一天突然爆掉的問題。而是一個慢慢累積的察覺——越來越多次，我看到它打了勾、宣稱完成，但心裡隱約覺得「等等，你真的跑過了嗎？」追問下去，發現這些 pattern 比我想像的常見：

- **說「測試通過」但沒跑測試。** 它寫完測試之後，基於對程式邏輯的理解直接告訴你結果，跳過了實際執行的步驟。
- **跑了部分測試就宣稱全部通過。** 它跑了它剛寫的那幾個測試，但沒跑整個 test suite。其他測試可能因為它的改動而壞了。
- **「已重構完成」但沒驗證行為不變。** 重構的定義是「改結構不改行為」，但它只確認了新 code 能跑，沒確認行為跟舊版本一致。

每一次，它的回報都讀起來很自信。「All tests passing.」「Refactoring complete, no behavioral changes.」如果你不追問、不自己跑一次，你不會知道這些宣稱背後有沒有實際的證據。

---

## 為什麼會這樣

這不是 AI 在「說謊」。更準確地說，它分不清「我相信這是對的」和「我已經證明這是對的」之間的差別。

對 AI 來說，寫完一段邏輯正確的測試 code，跟那段測試真的跑過並通過，在它的認知裡幾乎是同一件事。它對自己的推理有高度信心，所以從「這段 code 看起來會通過」到「測試通過了」之間的跳躍，對它來說不是一個有意識的省略，而是一個自然的結論。

但在工程的世界裡，這兩件事差了十萬八千里。

「我覺得這應該會動」跟「我跑了然後確認它會動」——中間隔的是整個 QA 的存在意義。

---

## Evidence Before Assertion

這個問題催生了一個原則，後來變成我整個 skill 體系裡最基本的規則：**Evidence before assertion。**

在宣稱任何工作「完成」之前，必須先執行驗證命令並確認輸出。說「測試通過」的前提是真的跑過測試。說「重構完成」的前提是真的驗證過行為不變。說「bug 已修」的前提是真的重現過 bug、修完之後再跑一次。

聽起來像廢話，對吧？但你試試看讓 AI 做十個任務然後回頭查，有多少次的「完成」真的有對應的驗證步驟。

這就是 `completion-gate` 這個 skill 的由來。

它做的事情很簡單：在任何完成宣稱之前，強制插入一個驗證步驟。不是叫 AI「請確認一下」——而是要求它實際執行驗證命令、貼出輸出、然後基於輸出來判斷是否完成。

具體來說：

- 宣稱「測試通過」→ 必須貼出 `npm test` 或等價命令的實際輸出
- 宣稱「重構完成」→ 必須跑 test suite 並確認沒有 regression
- 宣稱「bug 已修」→ 必須展示 bug 的重現步驟和修復後的驗證結果
- 宣稱「功能已實作」→ 必須展示功能的實際執行結果

沒有證據，就不能宣稱完成。就這麼簡單。

---

## 不只是 AI 的問題

寫到這裡我想坦白一件事：這個問題不完全是 AI 的錯。

在用 AI 之前，我也有類似的習慣——改完 code 之後覺得「應該沒問題」就直接 commit，忘記跑測試。差別只是在沒有 AI 的時候，這種疏忽的頻率比較低，因為每次改動都是自己寫的，心裡大概知道改了什麼。

AI 放大了這個問題，是因為**它幫你做了太多事，多到你根本不記得哪些需要驗證**。一個 session 裡改了五個檔案、加了兩個功能、修了一個 bug——你還記得每一個改動需要跑什麼驗證嗎？

`completion-gate` 不只是在管 AI，它也在管我。或者更準確地說，它把一個我本來就應該做、但經常忘記的步驟，變成了流程裡不可跳過的一環。

---

## 帶走一件事

下次 AI 跟你說「完成了」或「測試通過了」，不要問「你確定嗎？」——它永遠會說確定。

問它：「給我看證據。」

如果它給不出實際的執行結果，那它的「完成」就只是一個信念，不是一個事實。
