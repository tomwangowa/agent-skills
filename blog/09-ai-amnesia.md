# AI 失憶症

> *這是「當 AI 越來越好用，品質反而越來越差」系列的第 9 篇。*
> *這一篇講的是：AI 每次對話都從零開始，而你的工作不會。*

---

用 AI 寫 code 有一個很容易忽略的問題。不是幻覺、不是品質、不是速度——是**記憶**。

每一次你開啟一個新的 Claude Code session，AI 都不記得上一次的事。上次討論了什麼、做了什麼決定、改了哪些檔案、哪些事情做到一半——全部歸零。

你知道。AI 不知道。

---

## 「我們上次做到哪裡了？」

這個問題在小任務上不明顯。你開一個 session、修一個 bug、結束。下次開新 session 修另一個 bug。每次都是獨立的，不需要記憶。

但當你在做一個跨好幾天的專案時，事情就不一樣了。

第一天：你跟 AI 討論了架構方向，決定用 A 方案而不是 B 方案，理由是 X 和 Y。

第二天：你開了新 session。AI 不知道有 A 方案和 B 方案的討論。你要嘛重新解釋一次，要嘛直接叫它做，然後它可能會建議 B 方案——因為它不知道你昨天已經排除了。

第三天：你又開了新 session。這次你想不起來第一天的完整理由了。AI 也不記得。於是你們可能又花了 20 分鐘重新走一遍同樣的討論。

這不是 AI 的問題。這是**對話式介面的天生限制**：每個 session 是一個獨立的記憶空間，session 結束就清空。

---

## Git 不夠

你可能會說：code 的變更有 git 啊，看 commit log 就知道做了什麼。

對，git 記錄了「做了什麼」。但它不記錄「為什麼這樣做」和「還有什麼沒做完」。

commit message 寫的是 `refactor: extract auth middleware`。但你不會在 commit message 裡寫「我本來想用 session-based auth，後來跟 AI 討論了 30 分鐘，發現 JWT 在我們的架構下更簡單，所以改用 JWT，但 refresh token 的部分還沒做，打算明天處理」。

那 30 分鐘的討論——包含了決策的理由、被排除的選項、未完成的計畫——隨著 session 結束就消失了。

## 工作日誌的價值

我從以前就有寫工作日誌的習慣。但我都是從腦子裡回憶當天或是前幾天做了什麼，然後以寫日記的方式記錄下來。只不過有時比較忙就會落掉，所以工作日誌都是斷斷續續的。

但開始重度使用 AI 之後，我發現工作日誌變成了一個跟以前完全不同的東西：它不是給別人看的報告，而是**給下一個 session 的 AI 看的脈絡**。

我想：每個 session 結束時，我花 2 分鐘記錄「今天做了什麼、做了什麼決定、還有什麼沒做完」。下次開新 session 時，把這段紀錄丟給 AI。它瞬間就知道脈絡了——不需要我再花 10 分鐘口頭解釋，也不需要它從 git log 裡慢慢拼湊。

2 分鐘的紀錄，省下 10 分鐘的重新對焦。而且品質更好，因為我記錄的是**決策的理由**，不只是決策本身。

## 所以我造了這個

`activity-logger` 做的事情很簡單：在一個 session 結束的時候，把這次做了什麼記錄下來。

它會自動抓取：
- 目前在哪個專案、哪個 branch
- 改了哪些檔案
- 有沒有新的 commit
- 這次的工作脈絡

然後存成一個 JSON 檔案，放在 `~/.claude/activities/` 裡。

另一個 skill，`work-log-analyzer`，負責讀取和分析這些紀錄。你可以問它：

- 「這週我做了什麼？」
- 「上次關於 auth 的決定是什麼？」
- 「哪些 TODO 還沒完成？」
- 「SellerCheck 這個功能的實作歷程是什麼？」

它會從所有的 activity records 裡搜尋、整理、回答你。

這兩個 skill 合在一起，解決的不是「AI 的記憶問題」——AI 的記憶問題目前沒辦法從根本上解決（每個 session 就是會重新開始）。它們解決的是**工作脈絡的傳遞問題**：讓你在 session 之間不丟失重要資訊。

---

## 不只是 AI 的問題（第三次）

跟前面幾篇一樣，這個問題不完全是 AI 帶來的。

在用 AI 之前，你也會忘記兩週前為什麼做了某個決定。你也會在切換回一個暫停的專案時，花半小時重新搞清楚「上次做到哪裡」。

AI 放大了這個問題，是因為它把你的「工作單位」從「連續的幾天」切碎成「一個一個的 session」。以前你可能連續三天都在做同一件事，記憶是連續的。現在你可能每天開 3-5 個 session，每個 session 之間都有一次記憶斷裂。

斷裂的頻率變高了，但每次斷裂的成本不變——所以總成本上升了。

工作日誌不是什麼新概念。但在 AI 時代，它的投資報酬率比以前高得多。

---

## 帶走一件事

今天結束工作之前，花 2 分鐘寫下三件事：

1. **今天做了什麼決定？**（不是做了什麼，是決定了什麼）
2. **為什麼這樣決定？**（理由，不是結果）
3. **明天要從哪裡繼續？**

不需要工具，不需要 skill。一個文字檔就夠了。

明天你（和你的 AI）會感謝今天你寫的紀錄（其實是感謝你自己）。
